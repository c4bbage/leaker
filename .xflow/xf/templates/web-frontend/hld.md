## 8. 失败模式与降级策略

| 失败场景 | 影响 | 降级策略 | 恢复方式 |
| :--- | :--- | :--- | :--- |
| 后端 API 不可用 | [数据无法加载] | [显示缓存数据 / 友好错误提示] | [API 恢复后自动重试] |
| JS 运行时错误 | [页面功能异常] | [Error Boundary 兜底，不白屏] | [刷新页面] |
| 静态资源加载失败 | [样式/脚本缺失] | [CDN 降级到备用源 / 基本 HTML] | [资源恢复后正常] |
| 会话过期 | [操作被拒] | [重定向到登录页，保留原操作意图] | [重新登录] |
| 网络断开 | [请求失败] | [显示离线提示，不丢失已填内容] | [网络恢复后自动重试] |
