## 3. 错误码与前端处理

> 错误码定义与后端 contracts.md 一致，此处补充前端处理策略。

| 错误码 | HTTP 状态 | 语义 | 前端处理 | 可重试 |
| :--- | :---: | :--- | :--- | :---: |
| E4001 | 400 | 参数无效 | 表单字段提示 | 否 |
| E4011 | 401 | 认证失败 | 跳转登录页 | 否 |
| E4031 | 403 | 权限不足 | 提示无权限 | 否 |
| E4041 | 404 | 资源不存在 | 404 页面 / 提示 | 否 |
| E4291 | 429 | 频率限制 | 显示"请稍后重试" | 是（按 Retry-After） |
| E5001 | 500 | 服务器错误 | 通用错误提示 | 是（自动重试 1 次） |
| E5031 | 503 | 服务不可用 | 显示"服务暂时不可用" | 是（退避重试） |
