## 5. 中间件链

> 按执行顺序排列，靠前的先执行。

| 顺序 | 中间件 | 职责 | 失败时 |
| :---: | :--- | :--- | :--- |
| 1 | 请求 ID 注入 | 为每个请求生成唯一 ID，写入响应头 | — |
| 2 | 认证 | 验证 Token / Session，注入用户上下文 | 401 Unauthorized |
| 3 | 授权 | 检查权限 / 角色 | 403 Forbidden |
| 4 | 限流 | 按 IP / User 限制请求速率 | 429 Too Many Requests |
| 5 | 结构化日志 | 记录请求路径、耗时、状态码 | — |
| 6 | 错误处理 | 捕获未处理异常，统一错误响应格式 | 5xx |
