---
description: 查看项目状态：宪章、模块、活跃变更与进度概览
---

查看 xflow 项目的当前状态，包括产品定位、所有模块和进行中的变更。

不带参数：显示全局概览。

## 执行步骤

1. **项目级状态**：
   - 检查 `xspec/xf/constitution.md` 是否存在
   - 检查 `xspec/xf/PRODUCT.md` 是否存在
   - 读取产品定位摘要（如存在）

2. **扫描模块目录**：列出 `xspec/xf/modules/` 下所有已归档模块
   - 模块名称、类型、版本、最后更新时间

3. **检查当前变更**：读取 `xspec/xf/changes/change.yaml`（如存在）
   - 变更 ID、名称、当前阶段、受影响模块

4. **扫描归档目录**：列出 `xspec/xf/archive/` 下所有已归档变更

5. **格式化输出**：

```
📋 xflow 项目状态
====================

🔧 项目级
  宪章：✅ / ❌
  产品定位：✅ / ❌

📦 已归档模块 (N 个)
┌──────────────────┬──────────────┬────────┐
│ 模块名称          │ 类型         │ 版本    │
├──────────────────┼──────────────┼────────┤
│ user-auth        │ web-backend  │ v1.0   │
│ login-page       │ web-frontend │ v1.0   │
└──────────────────┴──────────────┴────────┘

🔄 当前活跃变更
┌──────────────────┬──────────┬──────────────────────┐
│ 变更 ID          │ 当前阶段  │ 受影响模块            │
├──────────────────┼──────────┼──────────────────────┤
│ 002-payment      │ detail   │ payment-api, checkout │
└──────────────────┴──────────┴──────────────────────┘
（无活跃变更时显示"当前无活跃变更，使用 /xf-brainstorm 开始新变更"）

📂 已归档变更 (N 个)
- 001-user-auth
```

6. **如果有活跃变更**，显示详细信息：
   - 变更元数据
   - 已生成的制品列表及状态
   - 任务进度（如有模块 task.md）
   - 建议的下一步操作（基于当前 phase）

7. **下一步建议对照**：

| 当前 phase | 建议下一步 |
| :--- | :--- |
| 无变更 | `/xf-brainstorm` 或 `/xf-clarify` |
| clarify | `/xf-design` |
| design | `/xf-detail` |
| detail | `/xf-task` |
| task | `/xf-analyze`（推荐）或 `/xf-implement` |
| implement | `/xf-archive` |
| archive | `/xf-archive`（归档进行中或上次中断，重跑可继续；如需回到 implement 接着开发，把 `change.yaml` 的 `phase` 改回 `implement` 再继续） |

## 行为规则

- 这是只读操作，不修改任何文件
- 如果没有宪章，提示先 `/xf-constitution`
- 如果没有产品定位，提示先 `/xf-product`
- 所有输出使用中文
